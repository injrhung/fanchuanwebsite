# 網站圖片

請將正式網站圖片放在此資料夾。

建議檔名：

- `logo.svg`：品牌 Logo
- `hero.webp`：首頁主視覺
- `meeting-bento.webp`：開會精緻便當
- `signature-bento.webp`：招牌便當
- `assorted-bento.webp`：多元餐盒
- `about.webp`：品牌／店面／廚房照片

目前網站使用的最佳化圖片為 `hero.jpg`、`meeting-bento.jpg`、`signature-bento.jpg`、`assorted-bento.jpg` 與 `storefront.jpg`。原始照片保留於分類資料夾中。
